## POST #7 — "Build Walkthrough" (Thursday, Week 2)

**Pillar:** Educational tactical
**Goal:** Demonstrate expertise, drive group authority

> Most Facebook ads lose 30% of their tracking data.
>
> Here's the fix that almost nobody implements:
>
> Meta's iOS 14.5 update broke browser-based ad tracking. The pixel still works, but it can't see what users do after they leave Facebook. That data goes dark.
>
> The fix: **Conversions API (CAPI).**
>
> CAPI sends conversion data from YOUR server directly to Meta's servers — bypassing the browser entirely. It captures the data the pixel misses.
>
> Setup options:
> - Through GHL → built in, takes 5 minutes
> - Through Stape.io → $20/mo, 15 minutes
> - Custom server-side → free, takes a day
>
> Meta's own data: advertisers using CAPI see 17.8% lower cost per result.
>
> If you're running ads and not using CAPI, you're leaving 1 in 6 conversions uncounted.
>
> Anyone need help setting it up? Drop a question below.
