Claude Code Slash Commands: The Cheat Sheet (What Each One Does)

By Ronnie Craig • June 30, 2026 • 5 min read

Most people use Claude Code with zero idea that slash commands exist — and then wonder why it feels slow or forgetful. These little commands (you just type a /) are the difference between fighting the tool and flying. Here's a clean, accurate cheat sheet of the ones actually worth knowing, grouped by when you'd reach for them.

What's a slash command? A shortcut you type starting with / that triggers a built-in action instead of being sent to the AI as a prompt. /clear, /model, /usage — that kind of thing.

🚀 Setting up a project

CommandWhat it does
/initCreates a CLAUDE.md project guide so Claude knows your stack, conventions, and key files
/memoryEdit your CLAUDE.md files or manage auto-memory
/add-dir <path>Give Claude access to an additional folder during the session
/configOpen the settings interface (alias: /settings)

💬 Managing your session & context

CommandWhat it does
/clearStart fresh with empty context (aliases: /reset, /new)
/compactSummarize the conversation to free up context while continuing
/contextVisualize how much context you're using
/resumeResume or switch between past conversations (alias: /continue)
/branchFork the conversation at the current point to explore an alternative
/rewindRoll back code/conversation to an earlier checkpoint (aliases: /checkpoint, /undo)
/exportExport the conversation to a file or clipboard

🧠 Models & usage

CommandWhat it does
/modelSwitch the AI model and save it as your default
/effortSet the reasoning effort level (low / medium / high, etc.)
/usageShow your cost, usage limits, and stats (aliases: /cost, /stats)
/usage-creditsConfigure extra usage credits (this replaced the old /extra-usage)

🛠️ Building & reviewing code

CommandWhat it does
/planEnter plan mode — Claude maps out the work before touching anything
/diffOpen an interactive viewer of your uncommitted changes
/code-reviewReview your diff for bugs and cleanups (can auto-fix or comment)
/security-reviewAnalyze pending changes for security vulnerabilities

🔌 Tools, integrations & customization

CommandWhat it does
/mcpManage MCP server connections (the way Claude plugs into your other tools)
/agentsConfigure subagents
/skillsList available skills
/permissionsManage allow/ask/deny rules for tools (alias: /allowed-tools)
/themeChange the color theme
/helpShow help and the full list of available commands

The 5 to learn first: /init (give it context), /clear (fresh start), /compact (trim a long chat), /model (right model for the job), and /usage (watch your limits). Those five alone fix most of the "Claude Code is slow/forgetful" complaints.

Claude Code adds and updates commands over time, and many have aliases. For the complete, current list, type /help inside Claude Code or check the official docs. This cheat sheet covers the commands most people actually use day to day.

Frequently Asked Questions

Slash commands are shortcuts you type in Claude Code starting with a forward slash (like /clear or /model) that trigger built-in actions instead of being sent to the AI as a prompt. They let you manage your session, switch models, review code, set up your project, and control tools quickly — without explaining what you want in plain English every time.
/clear wipes the conversation and starts you fresh with an empty context — use it when you're switching to a totally different task. /compact keeps going but summarizes the conversation so far to free up context space — use it when you want to continue the same task but the chat has gotten long. In short: /clear for a fresh start, /compact to keep momentum while trimming the clutter.
Type /usage. It shows your cost, current usage limits, and session stats. (/cost and /stats are aliases for the same command.) To configure extra usage credits, use /usage-credits.
/init creates a CLAUDE.md file — a project guide that tells Claude about your stack, conventions, and key files so it has context every session. Pair it with /memory to edit that file or manage auto-memory, and /add-dir to give Claude access to additional folders. Setting these up once dramatically improves the quality of everything that follows.
